# Changelog

## [Unreleased] 01-11-2026

### Added

- `documentation/`: gameplay, architecture, data formats, graphics, sound and source/toolchain chapters, plus
  `VERIFICATION.md` (what was checked in VICE, and source comments found to disagree with the code)
- `documentation/ROOMS.md`: generated atlas of all 52 rooms (screenshot, map position, tiles and classes,
  enemies, coins, items, decorations, mechanisms); `documentation/SOUND_DATA.md`: generated songs, tracks,
  patterns, instruments and effect records
- `documentation/MONTY_ON_THE_RUN.html`: offline handbook of every chapter with embedded screenshots, figures,
  animations and audio, generated by `tools/build_docs.mjs` (shared with Thing on a Spring; vendored Marked
  17.0.5 and Mermaid 10.9.3)
- `tools/build.py`: assembles either build, checks the byte-perfect image against `reference.sha256`, writes
  VICE symbol files, and restates Kick Assembler 5.25 errors as `file:line:col: error:`
- `tools/launch.py`: starts either build in VICE at `StartUp` from a raster line clear of the start-up race;
  `--check` (smoke test), `--runs`, `--unsafe` (reproduce the race)
- `tools/capture_screens.py`: VICE screenshots of the title, the hi-score table and all 52 rooms (built by the
  game's own `LoadRoom`), plus RAM dumps for checking the decoders
- `tools/render_graphics.py`: character set, tile library (framed by collision class), sprites, the 27 enemy
  types, Freedom Kit, special items, the 97 decorations, decoded rooms, world map, animated GIFs; `--verify`
  compares decoded rooms with the RAM dumps
- `tools/extract_sound.py`: PSID v2 `build/monty_on_the_run.sid` (3 songs, 16 effects) using the game's own
  driver, piano rolls, `SOUND_DATA.md`; `tools/render_audio.py`: recordings through `vsid`
- `tools/symbols.py`: label lookup from the symbol files, so the tools follow code that moves
- `reference.sha256`: SHA-256 of the original game binary (`$080E–$FF72`); the byte-perfect build is checked against it
- `justfile` recipes
- Where to download the C64 TrueType fonts (style64.org) and which files to copy: in the README's
  "Requirements", `documentation/HTML_DOCUMENTATION.md` and the `build_docs.mjs` notice
- `just verify` also runs the handbook check when the C64 fonts are in `tools/docs/fonts/`, and says where to
  download them when they are not
- `tools/check_cheat.py` and `just cheat-check`: VICE check that the cheat flag survives `startGame` and the
  cake appears in room `$01`
- `documentation/CREDITS.md`: credits and links for the game, Dave Agent's reconstruction (with
  ghidra-kickass-export), the documentation, every tool, library and font, and SID players; last in the handbook
- The Bon Voyage ending as `FreedomSequence` plays it: `capture_screens.py` captures the jetty, the boat and the sailing
  (with the passport) and the arrest (without), also alone with `--ending-only`; `GAMEPLAY.md` shows them
- `GAMEPLAY.md` "The C5 Road" and `VERIFICATION.md` "The Late C5 Rooms": rooms `$31`–`$33` are the last road screens
  before the boat, numbered after the ending; the evidence that they were added late; `ROOMS.md` links both
- `tools/doc_names.py` and `just docs-names` (run by `just docs-check`): fail if a chapter names a label that
  is in neither build's symbol file; placeholders go in `tools/doc_names_ignore.txt`

### Changed

- `.vscode/` removed and ignored: editor settings are personal and held a local `KickAss.jar` path; the
  documentation no longer refers to VSCode tasks. The MOSaic credit was removed (MOSaic was not used on this project)
  and the hi-score credit line now links to the data it comes from. `reference.sha256` was confirmed against the
  original image (it was first recorded from the build).
- `docs/` (the standalone HTML viewers) removed from the repository and ignored: they are generated and kept
  outside it, so the front page shows only the source, the documentation and the tools.
- `README.md`: documentation and quick-start sections; credits (Jason Perkins and Anthony Clarke, C64 code);
  removed the claim that the sprite engine multiplexes
- `.gitignore`: `build/`, `reference/`, `__pycache__/`, `tools/docs/fonts/`
- `documentation/ROOMS.md`: each room now lists the changes `ApplyItemRoomEffects` makes for items and the kit
  (rooms `$08 $0C $14 $19 $1C $22 $26 $2D $2F`)
- `render_graphics.py` writes only `room-map-00.png`, the one the documentation uses
- Handbook sidebar logo: Monty jumping (the somersault) and walking, side by side; the somersault
  animation is slowed to 0.15 s a frame (1.8 s a turn). `logo` in `handbook.json` now also takes a list of
  `{"src", "alt"}` images
- Documentation prose rewrapped at 120 columns, as in Frak and Thing on a Spring (the rendered text is
  unchanged); `HTML_DOCUMENTATION.md` titled "Monty on the Run – Maintaining the Documentation"
- Handbook groups renamed "The game and its code" and "Reference"; `VERIFICATION.md` moved to Reference, and
  `documentation/README.md` lists the chapters in the same two groups

### Fixed

- Refactored build: the I WANT TO CHEAT name had no effect, because `InitialiseZeroPage` started clearing at
  `$08`, which is `zp.cheat_mode`. It now starts at `zp.cheat_mode + 1` (`$09`). An `.errorif` guard keeps
  `sound_mode` and `sfx_sweep_dir` below the clear. The comments in `utils.asm`, `main.asm` and `zero_page.asm`
  are corrected. One byte of the program changes (`$1DC2`: `$08` to `$09`). Before and after are in
  `documentation/VERIFICATION.md`.
- `documentation/VERIFICATION.md` lists source comments that disagree with the code
- `documentation/VERIFICATION.md` said every decoded room cell matches VICE; 205 cells in 16 rooms are drawn
  at run time, and the table of causes is now there
- `documentation/HTML_DOCUMENTATION.md`: the style64.org link uses https
- `documentation/SOUND.md`: the leftover test harness has four routines, not three; the last two start at
  `$95CC` and `$95E3`, not `$95C9` and `$95DB`
- `documentation/VERIFICATION.md`: `$220A` is an instruction inside `CheckPiledriverContact` (entry `$21FE`);
  the multiplexer and credits entries describe the upstream README, which this README corrects
- `documentation/MONTY_ON_THE_RUN.html` regenerated: it was stale after a `CHANGELOG.md` edit
